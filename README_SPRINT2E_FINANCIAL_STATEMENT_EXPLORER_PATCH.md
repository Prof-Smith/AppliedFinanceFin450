# Sprint 2E Patch: Financial Statement Explorer

Upload the extracted contents to the root of your GitHub repository and overwrite:

What this build adds:

- Company selector for five teaching cases
- Financial statement snapshot cards
- Plotly trend chart for revenue, net income, and operating cash flow
- Plotly margin and cash conversion chart
- Plotly balance sheet snapshot chart
- Income statement, balance sheet, and cash flow statement table tabs
- Analyst prompt
- Previous/next navigation

Important note:

The included numbers are simplified teaching datasets for interface testing and classroom illustration. Replace them with current audited financial data before using the page for real investment analysis.
