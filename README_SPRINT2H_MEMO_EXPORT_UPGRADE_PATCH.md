# Sprint 2H Memo Export Upgrade Patch

Upload the extracted contents to the root of your GitHub repository and overwrite:

- modules/module1/challenge.html

This upgrade makes the memo exportable and more substantial.

Adds:
- Export HTML Report button
- Print / Save as PDF button
- Copy Markdown button
- Memo preview with embedded evidence map image
- Valuation interpretation field
- Evidence checklist in the exported report
- Visual support via Plotly.toImage export

How students export:
1. Complete the memo fields.
2. Select Build Memo Preview.
3. Select Export HTML Report for a downloadable file, or Print / Save as PDF to use the browser print dialog.
4. Select Copy Markdown if they need to paste into Word, Canvas, or another editor.
