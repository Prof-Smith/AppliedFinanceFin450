From ROIC diagnosis to valuation evidence

The Merck Chapter 5 example uses free cash flow valuation and multiples to evaluate whether model assumptions produce a plausible value. This page applies that same cross-check logic to AbbVie by comparing DCF value, trading multiples, and market-implied expectations.

Core idea: A valuation cross-check should test whether the company analysis is internally consistent. It should not turn a fragile model into a false sense of precision.
Responsible-use note: Default values are teaching placeholders. Students should update market capitalization, debt, cash, EBITDA, earnings, FCF, and peer multiple assumptions using current data before graded submission.
