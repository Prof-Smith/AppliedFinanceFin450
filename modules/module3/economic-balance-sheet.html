Text Connection

From accounting format to economic format

The Merck Chapter 5 example rewrites the balance sheet so the model can separate operating assets from financial assets and operating liabilities from financial debt. This page applies that same classification logic to AbbVie.

Analyst purpose: The economic balance sheet prepares the model for ROIC. ROIC requires NOPAT in the numerator and operating invested capital in the denominator.
Responsible-use note: Default values are teaching placeholders. Students should update these values using AbbVie filings or instructor-provided data before submitting a graded memo.
Inputs

Classify the balance sheet

Enter final-year values from the statement import page, then classify each line as operating or financial.

Economic Balance Sheet Map

Classification rules

Operating side
Operating current assets, operating current liabilities, net PPE, operating intangibles, and other operating assets become invested capital.
Financial side
Cash, marketable securities, short-term debt, long-term debt, and other financial claims are separated from operations and used to bridge enterprise value to equity value.
