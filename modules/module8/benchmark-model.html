Sprint 9BExpected return model

Benchmark Model: what return should we have expected?

An abnormal return is only as useful as the benchmark used to estimate expected return. This lab helps students compare a market-adjusted model, a beta-adjusted market model, and a simple risk-adjusted model so they can see how benchmark assumptions affect the event-study conclusion.

Analyst purpose: Students should explain why benchmark selection matters and how a different expected-return model can change the size, or even the interpretation, of abnormal return.
How the calculation works

Expected return is the comparison point

The benchmark model estimates the stock return that would have been expected absent the event. A simple market-adjusted model assumes the stock should move one-for-one with the benchmark. A market model adds alpha and beta. A risk-adjusted version can include a risk-free rate, market risk premium, or a factor-style premium.

Market-Adjusted Expected Return = Benchmark Return Market Model Expected Return = Alpha + Beta × Benchmark Return Risk-Adjusted Expected Return = Risk-Free Rate + Beta × Market Risk Premium + Optional Factor Premium Abnormal Return = Actual Return - Expected Return

No benchmark is perfect. The analyst should choose a model that fits the security and event context, then explain the sensitivity of the abnormal return to that choice.

Student checkpoint: Does the market reaction remain meaningful under more than one benchmark model?
