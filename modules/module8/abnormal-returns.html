Abnormal Returns: build the event-window evidence

This lab moves from one event-day calculation to a full abnormal-return table. Students enter daily stock returns and benchmark returns around the event, then calculate expected returns, abnormal returns, and cumulative abnormal returns across the event window.

Analyst purpose: Students should identify whether the market reaction is concentrated on the event date, starts before the event, or continues after the event.
How the calculation works

Daily abnormal returns and cumulative abnormal return

Each daily abnormal return compares the stock’s actual return with the expected return from the benchmark model. Cumulative abnormal return, or CAR, sums abnormal returns across the event window. This helps identify leakage, immediate reaction, and delayed reaction.

Expected Return_t = Alpha + Beta × Benchmark Return_t Abnormal Return_t = Actual Return_t - Expected Return_t CAR_t = Σ Abnormal Return_t from the start of the event window through day t

The event-day abnormal return is important, but the surrounding days matter too. A large pre-event abnormal return may suggest information leakage or anticipation. A large post-event abnormal return may suggest delayed processing or continued information arrival.

Student checkpoint: Is the reaction concentrated on Day 0, or does the evidence suggest leakage or delayed reaction?
