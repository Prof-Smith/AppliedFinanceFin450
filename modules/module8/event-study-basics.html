Event Study Basics: actual return, expected return, and abnormal return

An event study estimates how a security performed relative to a benchmark around a specific corporate event. If the stock return differs from the expected return, the difference is the abnormal return. Summing abnormal returns across an event window gives cumulative abnormal return, or CAR.

Analyst purpose: Students should understand what abnormal return measures and why market reaction evidence should be interpreted carefully rather than mechanically.
How the calculation works

From actual return to abnormal return

The simplest event-study model compares the stock return to a benchmark return, optionally adjusted by beta. The abnormal return estimates the portion of return not explained by the benchmark during the event window.

Expected Return = Alpha + Beta × Benchmark Return Abnormal Return = Actual Stock Return - Expected Return Cumulative Abnormal Return, CAR = Σ Abnormal Returns over the event window

This starter page uses synthetic event-window data for classroom demonstration. Later pages will focus on benchmark selection, abnormal return tables, event windows, and final briefing interpretation.
