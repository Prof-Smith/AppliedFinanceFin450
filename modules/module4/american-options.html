American options and early exercise

American options can be exercised before expiration. The binomial model is especially useful because it can compare continuation value with immediate exercise value at every node. This page shows why an American put may be more valuable than a European put, while early exercise of a non-dividend-paying call is typically not valuable in the standard teaching setup.

Analyst purpose: Students should identify where early exercise is optimal, explain the American option premium, and distinguish continuation value from immediate exercise value.

Early Exercise Rule

Continuation versus immediate exercise

Continuation value = [q × value at up node + (1 - q) × value at down node] / (1 + r)
Immediate exercise value = intrinsic value at the node
American option node value = max(continuation value, immediate exercise value)
