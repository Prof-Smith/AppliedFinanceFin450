Module Purpose

Build the valuation engine behind Module 1

Module 2 deepens the Module 1 analyst workflow by requiring students to build and defend WACC, operating FCF, pro forma forecasts, terminal value, sensitivity analysis, ROIC, and a professional Microsoft valuation memo.

Core question: Where do the DCF assumptions come from, and how should a responsible analyst defend them?
Integrated Improvements

What has been strengthened

Text alignment cards
Every Module 2 page now includes a card connecting the activity to Chapter 3 or Chapter 4.
Pro forma statement modeling
The Pro Forma Builder now includes projected income statement, operating balance sheet, invested capital, and FCF schedule views.
Model validity warnings
Mid-year DCF, sensitivity, and case pages now emphasize WACC greater than terminal growth, terminal value dependence, and assumption fragility.
Responsible stewardship
The Microsoft case now includes data verification, teaching-assumption labeling, exportable memo, and educational-use disclaimer.
