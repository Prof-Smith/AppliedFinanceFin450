Build the WACC

Use market-value weights and after-tax debt cost. If net debt is negative, debt weight is set to zero.

WACC = E/(E + D) × rE + D/(E + D) × rD × (1 − TC)
Capital structure note: Net debt treatment will update as assumptions change.
