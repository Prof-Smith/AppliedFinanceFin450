Deal thesis and standalone value

A transaction recommendation begins with a simple question: what is the target worth before the deal? Students compare the target’s standalone value with the offer price and estimate the amount of value creation required to justify the premium.

Analyst purpose: Students should separate the target’s standalone business value from the transaction story. A deal can sound strategic and still destroy value if the premium is too high or the synergy case is weak.
How the calculation works

From standalone value to required synergy

The first deal screen compares the target’s equity value or enterprise value with the proposed offer value. If the acquirer pays above standalone value, the premium must be justified by credible synergies, strategic benefits, or restructuring gains.

Offer Premium = Offer Value - Standalone Value Premium % = Offer Premium / Standalone Value Required Synergy = max(Offer Value - Standalone Value, 0) Value Surplus = Credible Synergy - Required Synergy

This page does not decide the full transaction. It establishes the burden of proof. Later pages test whether the synergy, financing, and risk evidence can support the price.

Student checkpoint: What value must be created after the deal just to break even on the premium?
