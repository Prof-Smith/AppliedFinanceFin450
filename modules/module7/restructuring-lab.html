Restructuring Lab: proceed, renegotiate, restructure, divest, or reject?

After evaluating standalone value, synergy support, financing structure, EPS impact, and debt capacity, analysts should not default to a simple yes-or-no acquisition recommendation. A weak deal may be improved through a lower price, different financing mix, divestiture, carve-out, operational restructuring, or rejection.

Analyst purpose: Students should convert the transaction evidence into a practical recommendation path and identify what must change for the deal to become financially defensible.
How the calculation works

From deal evidence to restructuring recommendation

This lab translates prior deal screens into comparable strategic alternatives. Each path has a value effect and an execution risk. The strongest recommendation is not always the highest raw value path. It is the alternative with the best risk-adjusted value, clear feasibility, and a defensible reversal condition.

Risk-Adjusted Path Value = Estimated Value Creation × Feasibility Weight - Execution Cost Proceed Value = Deal Surplus + Synergy Surplus - Financing Risk Penalty Renegotiate Value = Price Reduction Benefit + Synergy Surplus - Renegotiation Risk Cost Restructure Value = Operating Improvement Value - Restructuring Cost Divest Value = Sale Proceeds + Focus Benefit - Separation Cost Reject Value = Avoided Value Gap + Avoided Financing Risk

The purpose is to show that a deal recommendation can be conditional. “Proceed” may be appropriate if the premium is covered and the balance sheet survives downside stress. “Renegotiate” or “restructure” may be preferable when value exists but the current terms are fragile.

Student checkpoint: Which recommendation creates the strongest value after execution risk, and what condition would reverse the decision?
