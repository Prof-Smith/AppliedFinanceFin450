Strategic Flexibility Memo

You are preparing a strategic investment memo for a management committee. The committee has seen the standard NPV analysis, but the project includes managerial flexibility: the firm may be able to expand, abandon, stage, or wait. Your task is to identify which flexibility path is most defensible and explain how it changes the recommendation.

Required analytical spine: project context → static NPV → expansion option → abandonment option → staged investment → timing option → best flexibility path → double-counting caution → recommendation and reversal condition.

Assessment Rubric

Module 6 case scoring guide

Static NPV and project context, 15%

Clearly explains the baseline project value and fixed-path recommendation.

Real option interpretation, 25%

Accurately explains expansion, abandonment, staging, and timing flexibility.

Strategic recommendation, 20%

Identifies the most defensible flexibility path and ties it to a managerial action.

Double-counting and feasibility judgment, 15%

Avoids mechanically adding overlapping option values and evaluates actionability.

Responsible stewardship, 15%

Communicates uncertainty, limitations, credibility conditions, and reversal triggers.

Professional memo quality, 10%

Uses concise, evidence-backed writing with a clear recommendation.
