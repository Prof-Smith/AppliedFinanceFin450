Option to Abandon: the value of downside protection

A standard NPV calculation assumes management remains committed to the project path even when conditions deteriorate. An abandonment option recognizes that management may be able to stop the project, sell assets, or redeploy resources when results are poor. This downside flexibility is economically similar to a put option.

Analyst purpose: Students should explain when a project with weak or negative fixed-path NPV can become more attractive because management can limit downside losses.
How the calculation works

Abandonment flexibility as a put option

An option to abandon is similar to a put option. Management can stop the project, sell assets, recover salvage value, or redeploy resources if project value falls below the exit value. The “underlying asset” is the remaining project value. The “exercise price” is the abandonment or salvage value.

Underlying value, S = PV of remaining project cash flows Exercise price, X = Abandonment or salvage value Abandonment option ≈ Put option value Adjusted Project Value = Static Project NPV + Net Abandonment Option Value

The model estimates the value of downside protection. Higher uncertainty can increase abandonment value because the ability to exit poor outcomes becomes more valuable. Exit costs reduce that value because shutting down, selling assets, or redeploying resources may not be free.

Student checkpoint: Explain whether the exit path is legally, operationally, and financially feasible. If management cannot realistically abandon, the option value should not change the recommendation.
