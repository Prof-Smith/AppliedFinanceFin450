Staged Investment: value learning before full commitment

A staged investment lets management commit capital in phases. The first stage buys information. If results are favorable, management proceeds to scale. If results are unfavorable, management can stop before committing the full investment. Staging can reduce downside exposure while preserving upside opportunity.

Analyst purpose: Students should distinguish a full-commitment project from a staged project that pays for learning and preserves decision flexibility.
How the calculation works

Staging as a learning option

A staged investment separates a project into phases. Stage 1 buys information. After learning from Stage 1, management can continue, stop, redesign, or delay the larger Stage 2 commitment. The value comes from avoiding full commitment before uncertainty is partially resolved.

Full Commitment NPV = PV of full project cash flows - Full project investment Continuation Value = (PV if favorable - Stage 2 investment) / (1 + r)^delay Stop Value = max(PV if unfavorable - Stage 2 investment, 0) / (1 + r)^delay Expected Staged Value = -Stage 1 investment + p(Continue Value) + (1-p)(Stop Value) Value of Staging = Expected Staged Value - Full Commitment NPV

The probability of a favorable signal controls how often the project reaches the valuable continuation path. The learning value haircut can be used when the Stage 1 signal is noisy, incomplete, or not fully actionable.

Student checkpoint: Identify what Stage 1 teaches. If Stage 1 does not produce useful information before Stage 2, staging may simply delay the project rather than create real option value.
