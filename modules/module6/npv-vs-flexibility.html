NPV can miss strategic flexibility

Traditional NPV treats the investment path as fixed. Real options analysis asks whether managers can adapt after uncertainty is revealed. This first lab compares a static project NPV with a flexibility-adjusted project value.

Analyst purpose: Students should see that a negative static NPV may become acceptable if managerial flexibility has sufficient value.
