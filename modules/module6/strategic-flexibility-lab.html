Sprint 7FStrategic flexibility dashboard

Compare expand, abandon, stage, and wait decisions

This lab consolidates the real-options evidence from Module 6. Instead of looking at flexibility one option at a time, students compare four forms of managerial flexibility and decide which decision path is most defensible.

Analyst purpose: Students should learn that real options are not automatically additive. The best recommendation depends on which flexibility is credible, actionable, and most relevant to the decision.
How the calculation works

From option values to a decision dashboard

The dashboard uses saved evidence from earlier Module 6 pages when available, then lets students apply credibility weights to each flexibility type. The purpose is not to mechanically add every possible option. The purpose is to identify which strategic path has the strongest evidence.

Credibility-Adjusted Value = Raw Option Evidence × Credibility Weight Best Strategic Path = Highest credible value contribution, after considering static NPV and feasibility Decision Rule = Choose the flexibility path that is valuable, feasible, and tied to an actual managerial action

In practice, several forms of flexibility may overlap. For example, staging may include an embedded option to abandon or expand. Students should avoid double-counting by explaining which option is the primary decision path.

Student checkpoint: Which flexibility is most credible in this case, and what managerial action makes it real?
