# Sprint 2F Patch: Ratio Analysis Studio

Upload the extracted contents to the root of your GitHub repository and overwrite:

- modules/module1/ratio-analysis.html

What this build adds:

- Company selector using the same simplified teaching cases as the Financial Statement Explorer
- Profitability, liquidity, leverage, and efficiency scorecards
- Interactive Plotly financial health radar chart
- Interactive profitability trend chart
- DuPont analysis preview
- Latest-year ratio table with traffic-light signals
- Analyst prompt
- Previous/next navigation

Important note:

The included scores are pedagogical heuristics, not investment ratings. They are designed to help students learn how to interpret ratio categories, not to produce real buy/sell decisions.

After upload:

1. Open modules/module1/ratio-analysis.html
2. Hard refresh:
   - Windows: Ctrl + F5
   - Mac: Cmd + Shift + R
