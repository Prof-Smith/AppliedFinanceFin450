Analyst Purpose

Value the operating business

Use base free cash flow, an explicit growth path, WACC, and terminal growth to estimate enterprise value. Then bridge from enterprise value to equity value using debt, cash, and diluted shares.

Enterprise Value = PV of Forecast FCF + PV of Terminal Value
Professional standard: Report a valuation range and a reversal condition. Do not present one target price as certainty.
